# Edvibe: разбор скриншотов 33–65

Контекст (32.png, только для связки): преподаватель на странице **Classes** открыл модалку **«Create a class»** с тремя вариантами: «Individual class — Online lessons with a student 1 on 1», «Group class — Online lessons with multiple students», «Online courses — Online course where the student completes lessons independently».

**Общий каркас интерфейса преподавателя (виден почти на всех кадрах):**
- Шапка: логотип Edvibe, иконка «сетка приложений» (9 точек), плашка **«More opportunities ✦»** с цветной полосой прогресса и крестиком, **«Help»** с красной точкой-уведомлением, зелёная пилюля с галочкой (назначение по скриншотам не понять), колокольчик уведомлений, стрелка-дропдаун, аватар «I» (аккаунт преподавателя Iskander — имя видно на 49 и 58).
- Левый сайдбар: иконки без подписей: «?», «шапочка выпускника», «человек», «книга», «календарь», «таблица/расписание», «карта/кошелёк», «шестерёнка». По открытым страницам можно понять назначение только четырёх: «?» = Welcome (42), шапочка = Classes, человек = Students, книга = Materials. Что за остальными, на этих кадрах не видно.
- Внизу справа две плавающие кнопки: подарок (бонусная программа) и чат поддержки.
- Интерфейс на английском. Модалки сделаны в одном стиле: градиентная полоска сверху, крупный эмодзи, заголовок, кнопки Cancel/primary.

## Покадровый разбор

### 33.png: создание индивидуального класса (шаг 2)
- **Экран/роль:** Classes → модалка «Individual class». Роль: преподаватель.
- **На экране:** стрелка «назад» (вернуться к выбору типа класса), заголовок «Individual class», крестик. Поле **Cover**: превью обложки (чёрный квадрат с зелёной молнией; похоже на логотип, а не на стандартную обложку Edvibe, но наверняка сказать нельзя) и кнопка **«Upload»**. Поле **Class name** со значением «Timur». Кнопки **«Cancel»** и **«Create»**.
- На фоне страница Classes: поиск «Searching for classes», чипы-фильтры **All / Individual / Group / Marathons**, переключатель вида «плитка/список», за модалкой просвечивает кнопка «Create class».
- **Функции:** класс создаётся в два шага: тип, потом название и обложка. Есть тип «Marathons» (марафоны) как отдельный фильтр.
- **Связь:** на 32 выбран «Individual class».
- **UX:** минимальная форма из двух полей. Класс 1-на-1 назван именем ученика, то есть «класс» здесь по сути карточка ученика/пары.

### 3) Топ-10 решений для нашего MVP

1. **Инвайт-ссылка в класс с автоматическим вступлением (38, 49).** Ученик открывает ссылку, регистрируется или входит и сразу оказывается в классе. Для репетитора это самый быстрый способ подключить ученика. Плюс кнопка перевыпуска ссылки.
2. **Три способа добавить ученика: By the link / Manually / Existing (38, 39, 48).** Ссылка подходит для самостоятельных учеников, ручной режим для детей и тех, кто «не справится сам», выбор из существующих для повторного использования в группах.
3. **Готовый блок «данные для входа» с одним «Copy» (40, 45).** Репетиторы общаются с учениками в мессенджерах, поэтому скопировать готовое сообщение одним кликом очень удобно. Пароли при этом стоит делать надёжнее 4 цифр.
4. **Беспарольный вход ученика (email + код, Google) и страница с именем преподавателя (49–51).** Минимум трения и больше доверия. Учесть их ошибки: не просить подтверждать email после Google и не путать «code» и «password».
5. **Класс 1-на-1 как основная сущность, со своим расписанием, часовым поясом, учениками и статистикой (36).** Это совпадает с моделью работы репетитора, а часовые пояса критичны для онлайн-занятий.
6. **Иерархия материалов: учебник → урок → секции → упражнения, плюс блок «Exercises for homework» в том же уроке (58–60).** Домашка встроена в урок, отдельный модуль ДЗ в MVP не нужен.
7. **Один экран для превью и редактирования и кнопка «Invite a student» прямо из редактора (60).** Короткий путь от подготовленного урока к занятию.
8. **Инструменты урока для английского: личный словарь с тренажёром, неправильные глаголы с озвучкой, таймер, доска, чат и заметки (61–65).** Словарь и тренажёр дают ученику повод возвращаться между уроками и хорошо дифференцируют продукт. Таймер и глаголы дёшевы в реализации.
9. **Онбординг-чек-лист с наградой («создай класс, упражнение, ученика»), Welcome-страница, видео и Quick Guides (41, 42, 56).** Ведёт к «aha-моменту» и конверсии в оплату. Для MVP достаточно чек-листа и пустых состояний с одним CTA, геймификацию можно отложить.
10. **Прозрачная база учеников: статус активации и «не входил», бейдж класса с тултипом-сводкой, разные кнопки для учеников с классом и без (45–47, 52).** Преподаватель сразу видит, кто не подключился. Плюс AI-кнопка «Generate» рядом с ручным созданием (58) как ориентир для будущего AI-модуля.

**Ограничения и недочёты конкурента, которых стоит избежать:** неподписанные иконки сайдбара и панели инструментов; одна и та же заглушка «про словари» на всех инструментах; «Add a lesson» открывает «New unit»; «enter the 4-digit code» при плейсхолдере «Enter the password»; имя из Google-профиля не подставляется (у ученика вместо имени email); пароли из 4 цифр; грамматическая ошибка «1 tasks».
